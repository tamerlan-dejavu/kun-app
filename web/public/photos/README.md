# Фотографии Алматы для сайта

Положите сюда файлы с этими именами — они автоматически встанут на главную (в ч/б):

| Файл | Что снять | Формат |
|---|---|---|
| `hero.jpg` | двор или улица на фоне гор, люди в кадре | вертикальный 4:5 |
| `places-1.jpg` | советский двор, лавочки, деревья | горизонтальный 16:10 |
| `places-2.jpg` | интерьер или вход небольшой кофейни | квадрат |
| `people.jpg` | 3–5 человек со спины или вполоборота | горизонтальный 3:2 |

Настоящий город, не реклама и не сток. Нужны права на использование снимков.
Люди в кадре — с их согласия. Описания мест — в `src/content/photos.ts`.
